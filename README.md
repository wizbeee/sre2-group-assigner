# 과학탐구실험2 분반(팩)별 조 편성

팩(분반)을 고르고 **조 배정하기**를 누르면 실험실 좌석 도면의 6개 실험대에 조별 학번·이름이 배치되는 웹 도구입니다.
학생 명단은 **암호화되어** 있어서 비밀번호를 아는 사람만 볼 수 있습니다.

**주소: https://wizbeee.github.io/sre2-group-assigner/**

## 사용법

1. 주소 접속 → **비밀번호 입력** (기기당 한 번. "이 기기에서 기억하기"를 켜두면 다음부터는 바로 열립니다)
2. **팩(분반) 선택** → **조 배정하기**
3. 도면에 6개 조가 채워집니다.
   - **다시 배정** — 매번 새로 추첨
   - **인쇄 / PDF** — 도면 1쪽 + 조별 명단 1쪽 (A4 세로·가로 모두 한 쪽에 들어갑니다)
   - **CSV 저장** — 팩·조·학번·반·번호·이름 (엑셀에서 바로 열림)
   - **🔒 잠금** — 공용 PC에서 쓴 뒤 저장된 비밀번호를 지웁니다

## 조 편성 규칙

- 6개 조, 조별 인원 차이는 최대 1명 (예: 27명 → 5·5·5·4·4·4)
- **같은 반 학생은 서로 다른 조로** 배정 (인원 많은 반부터 그리디 배치 → 교환 기반 국소 개선)
- 팩마다 같은 반이 최대 4명(< 6조)이라 15개 팩 전부 같은 반 중복 0명이 가능하고, 시뮬레이션으로 확인했습니다
- 도면 기준: 교탁 쪽 앞줄이 1·2·3조, 뒷줄이 4·5·6조, 오른쪽 창문 2개, 왼쪽 아래 출입구

## 개인정보 처리

- 명단은 **AES-256-GCM**(키 유도: PBKDF2-SHA256 600,000회, 임의 salt/IV)으로 암호화해 `index.html` 안에 **암호문으로만** 들어갑니다.
- 저장소와 웹사이트 어디에도 평문 명단이 없습니다. 복호화는 전적으로 접속자의 브라우저 안에서만 일어나고, 입력한 비밀번호나 명단이 서버로 전송되는 경로는 없습니다.
- 평문이 들어가는 파일(`index.plain.html`, `exclude.local.json`, 명렬 `*.xlsx`)은 `.gitignore` 로 막아 두었습니다. **절대 커밋하지 마세요.**
- 비밀번호가 유출되면 새 비밀번호로 다시 빌드해서 푸시하면 됩니다(아래).

## 명단 갱신 · 비밀번호 변경

```bash
pip install openpyxl cryptography
python build.py "명렬 폴더 경로"
```

- 폴더 안의 `과학탐구실험2NN_교사_실험실(N명).xlsx` 를 모두 읽습니다(`과학탐구실험2` 뒤 두 자리 = 팩 번호, 12·13·14팩은 뒤에 `4A` 가 붙음).
- 폴더 경로는 인자 > 환경변수 `SRE2_ROSTER_DIR` > `roster_dir.local.txt` > `./rosters` 순으로 찾습니다.
- 비밀번호는 실행 중 입력받습니다(환경변수 `SRE2_PASSWORD` 로도 지정 가능). **다른 비밀번호를 넣으면 그게 새 비밀번호가 됩니다.**
- 결과: `index.html`(암호화, 배포용) + `index.plain.html`(비밀번호 없이 열리는 **로컬 전용**본, 커밋 금지)
- 그다음 `git add index.html && git commit -m "명단 갱신" && git push` 하면 주소에 바로 반영됩니다.

화면·로직을 고칠 때는 `template.html` 을 고친 뒤 `build.py` 를 다시 실행하세요.

## 수강 제외 학생

명렬에는 있지만 실제로 수업에 들어오지 않는 학생은 `exclude.local.json` 에 적습니다(이 파일은 커밋되지 않습니다).

```json
{ "<팩번호 2자리>": ["<학번>", "<학번>"] }
```

학번이 명렬에 없으면 빌드가 중단되므로 오타를 바로 알 수 있습니다. 예시는 `exclude.example.json` 참고.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 배포본. 앱 + 암호화된 명단 (GitHub Pages 가 이 파일을 서빙) |
| `template.html` | 화면·로직 원본. 명단 자리는 `/*__DATA__*/` 플레이스홀더 |
| `build.py` | 명렬 xlsx 파싱 → 암호화 → `index.html` 생성 |
| `exclude.example.json` | 수강 제외 학생 파일 예시 |
| `index.plain.html` | 로컬 전용(평문). `.gitignore` 대상 |
